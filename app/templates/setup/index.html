ConfigLake Setup

Complete these steps to get started. This wizard runs once.

1
Master Encryption Key
Protects all secrets stored in ConfigLake

ConfigLake uses envelope encryption: each environment has its own key, but all those keys are wrapped with a single master key that only you control.

Generate the master key below, then copy and store it safely (password manager, secrets manager, or a secure note). If you lose it, your secrets cannot be recovered.

This key will be written to your .env file. For production, move it to a proper secrets manager or inject it as an environment variable.
2
Create Admin Account
This account will have full access to ConfigLake
